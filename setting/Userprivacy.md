# CausalAgent 用户隐私说明

## 普通用户数据

CausalAgent 会保存完成登录、会话恢复、文件管理和因果分析所必需的数据，包括账号标识、会话与消息、聊天附件、上传文件、分析任务与事件以及运行恢复所需的 checkpoint。密码只保存不可逆哈希；Cookie、Token、数据库口令和其他密钥不作为业务内容保存。

普通用户只能访问自己的会话、文件和任务。普通用户前端、聊天 API、Job/Event 与 SSE 契约不因管理员后台而改变。

## 管理员只读访问

经后端实时确认的管理员可以在受保护后台查看业务概览、用户账号状态、会话和消息元数据、任务与事件、文件元数据以及数据库运行结论。列表不会返回密码哈希、完整正文、文件 BLOB、文件哈希、Cookie、Token、数据库账号 host 或 grants。

消息正文、聊天附件以及任务输入、结果和错误只在管理员明确点击后分块读取，每次最多 64 KiB。文件只支持受限 CSV 文本预览和附件式下载；CSV 预览最多读取 256 KiB、100 行、50 列，每个单元格最多 1000 字符，不执行公式、HTML 或脚本。

## 审计和文件访问记录

敏感访问会记录管理员、动作、目标标识、成功/拒绝/失败结果、错误码、request ID 和时间，不记录被查看的正文、文件内容、密码或密钥。成功敏感读取在审计不可写时会被拒绝。

文件预览或下载成功后，系统会在同一事务中增加该文件的访问次数并更新最近访问时间，同时写入不含文件正文的审计事件；不会因此改写文件内容。

## 数据库 deep 审计

管理员可手动请求 deep 数据库审计。该审计由独立 monitor 执行，只返回 migration、关键 schema、运行时、账号职责、数据关系和从库状态的脱敏结论；不展示真实数据库账号、host 或 grants，不自动修复或修改业务数据，也不会定时自动运行。

如需处理账号、会话、文件或审计数据相关问题，请联系当前 CausalAgent 部署的维护者。部署者应按适用法律和组织政策配置访问权限、备份、保留期限及安全传输。
